## Dated live configuration evidence

Read-only VPS snapshot on **2026-07-23**: `novostroy-bot-api.service` and `novostroy-bot-n8n-bridge.service` were `active/running`; global runtime file selected `V2`; V2 composer mode was `publish`; V3 composer mode was `shadow`; repeating bridge status updates were absent from env and therefore disabled by default. Architecture evidence after the local optimization: per-session serialization, terminal outcome and delivery status are explicit runtime markers. State-version CAS remains intentionally unresolved; the current single-process safety contract relies on per-session serialization plus atomic JSON-file replacement and must be revisited before multi-worker state access.

## Developer/test baseline

Fast local checks are intentionally no-secret, no-network and no-model-call. The baseline route is `python scripts/nmbot_check.py docs --dry-run`, then the relevant scope without `--dry-run` when the developer accepts the listed commands. The `audit` scope is source-only and produces review candidates, not unused-file or production claims. Full repository pytest, live Jivo smoke, deployment and release verification are outside steps 0–6 and require a separate stop/go decision.

CI exists at `.github/workflows/nmbot-local-fast-gate.yml` and runs `docs contracts quality` on push, pull request and manual dispatch with Python 3.12. The quality scope is deterministic fixture replay, not a provider/model call or production answer proof. The manifest time labels remain qualitative; dated machine-specific p50/p95 measurements are recorded through `scripts/nmbot_check_benchmark.py` and do not constitute production latency evidence.

Manual consumer map sanity checks:
- Prompt/runtime text change → V0 or V2 owner TBD → corresponding `nmbot check v0` or `v2`, then live Jivo only in release phase.
- Search-contract change → V2/contracts owner TBD → `nmbot check v2` plus contract consumer tests.
- Callback change → callback owner TBD → `nmbot check contracts`; no Sheets/network write in local check.
