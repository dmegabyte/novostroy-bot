# NMBOT response-model probes — 2026-07-22

## Цель

Сравнить модели для узкой задачи: из структурированных фактов о трёх ЖК
собрать естественные русские мини-презентации без выдумок, повторов и потери
строгого JSON-контракта.

Это read-only model-only probe. MCP, production runtime, Jivo и код не
изменялись. Eval не запускался.

- Контракт: текущий `ResponseBrief` и `prompts/v2_response_composer.txt:19-58`.
- Один gateway request на модель, без repair/retry.

## Вывод

На текущем `ResponseBrief` все модели повторяют одну закономерность: они
выбирают удобные поля, игнорируют семейную инфраструктуру и иногда делают
выводы о бюджете/переезде, которых нет в фактах. Значит, основной дефект в
контракте входных данных и recipe, а не только в выборе модели.

Для следующего эксперимента нужен узкий presenter-контракт: deterministic code
заранее выбирает допустимые факты и единственный угол каждой карточки, а модель
только связывает подготовленные факты в русские предложения. Flagship-модели
не оправданы до исправления этого контракта.
