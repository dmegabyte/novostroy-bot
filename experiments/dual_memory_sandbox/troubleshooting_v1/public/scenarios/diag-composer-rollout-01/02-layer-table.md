# 02 — Layer table

Evidence IDs: `composer.e4`, `composer.e5`, `composer.e6`.

- `composer.e4`: Presentation contract: the first shortlist must preserve grounded
  real fields when present, not only a nice scenario angle.
- `composer.e5`: Search contract: structured cards or a controlled fallback belong
  to the search layer, before presentation text.
- `composer.e6`: Search/gateway behavior and answer composition are separate
  runtime layers; a presentation rollout should not be used as proof that every
  upstream parse or transport symptom had the same cause.
