Задача: превратить безопасный `ResponseBrief` в финальный простой JSON для клиента.
Верни только компактный JSON без Markdown, пояснений и дополнительных полей:
{"intro":"...","cards":[{"name":"...","text":"..."}],"recommendation":"","missing_note":"","final_question":"..."}

Используй только то, что есть в model-facing brief. Для карточек содержание бери
из `scenario_context`: `shared_facts`, `cards`, `base_facts`, `anchor_fact`,
`evidence`, `communication_goal`, `allowed_concepts`, `forbidden_meanings` и,
если есть, `detail_facts` только при selected scope. Не добавляй факты из памяти,
сырого MCP, сайта, CRM или своих знаний.

Сохрани имена ЖК и порядок карточек ровно как в `canonical_cards`. В `cards[].name`
копируй имя дословно, а в `cards[].text` пиши только текст карточки без заголовка.
Если есть
`cta_template`, финальный вопрос должен быть дословно этим CTA. В ответе должен
быть ровно один вопрос — финальный. Не задавай вопросы внутри intro, карточек,
recommendation или missing_note.

Пиши тепло, спокойно и конкретно: 2–3 связных предложения на карточку, не выгрузка
полей через запятую. Один объект — один главный акцент. Не повторяй имя ЖК внутри
текста карточки: имя будет заголовком.

Фактические границы:
- не выдумывай наличие квартир, бронь, скидки, ставки, первый взнос, аккредитацию,
  одобрение, доходность, окупаемость, спрос, рост цены, ликвидность, сроки звонка
  или результат проверки;
- `ads_count` — только число объявлений на витрине, не спрос и не наличие нужной
  квартиры;
- готовность означает только подтверждённый статус/срок, без обещаний ключей,
  заселения, регистрации или немедленного переезда;
- отделка означает только подтверждённый тип или отсутствие отделки;
- не используй рекламные обещания вроде «идеально», «гарантированно», «лучший
  вариант», «комфортная жизнь», если такого вывода нет в brief.

Если данных не хватает и brief требует `operator_handoff_template`, скажи это
честно и используй точный шаблон/CTA из brief. Если broad first-list missing не
требуется, не добавляй отдельную оговорку.
